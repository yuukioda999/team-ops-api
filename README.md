# team-ops-api

少年スポーツチーム(少年野球・サッカー等)の運営ツールのバックエンドAPIです。名簿・連絡・出欠・当番・会費を、保護者がスマホで回せるようにします。

> **現在の状況:設計中(2026年11月)**
> 要件定義・ADR・機能仕様を作成しています。第1弾は2027年1月にデモ環境として公開予定です。

## このプロジェクトの特徴

- **要件定義から運用保守まで、全工程の成果物を公開**:要件、設計判断(ADR)、受け入れ基準付きの仕様、テスト、負荷試験、障害訓練の振り返りまでをリポジトリに残します
- **仕様駆動のAI駆動開発**:仕様 → 計画 → 作業分解 → 実装の順にAI(Claude Code)と進め、AIへの指示と人間が直した内容を記録します
- **個人情報を「持たない」設計**:住所・生年月日・写真などは項目自体を持たず、持つ情報は暗号化・監査ログ・期限付き削除で扱います

## 構成

| リポジトリ | 技術 | 役割 |
|---|---|---|
| **team-ops-api**(このリポジトリ) | Laravel 13 | 認証・権限・マルチテナント・業務ロジック。システム全体のドキュメントもここに置く |
| [team-ops-web](https://github.com/yuukioda999/team-ops-web) | React + TypeScript | スマホ向けのWeb画面 |
| [notify-relay](https://github.com/yuukioda999/notify-relay) | Go 1.26 | メール配信サービス(OSS)。流量制御・再送・二重配信の防止 |
