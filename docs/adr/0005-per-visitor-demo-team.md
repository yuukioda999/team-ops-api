# ADR-0005: デモは訪問者ごとに見本チームを複製して提供する

- ステータス: 承認
- 日付: 2026-11-05
- 決定者: 小田 裕貴
- 関連: ADR-0003、specs/007-demo-mode

## コンテキスト

- デモ環境は、面接官などが登録なしで全機能を試すためのもの
- 訪問者はお知らせの送信や名簿の削除など、データを変更する操作も試す
- 訪問者が入力した内容(不適切な文章を含む)が、他の訪問者に見えるのは避けたい

## 検討した選択肢

| 案 | 内容 | 評価 |
|---|---|---|
| A | 全員で1つのデモチームを使い、毎晩元に戻す | 実装は最も簡単。ただし他の訪問者の操作結果やいたずらが見え、時間帯によっては散らかった状態で試すことになる |
| **B** | **「デモとしてログイン」のたびに見本チームを訪問者専用に複製し、24時間で削除する** | **訪問者どうしが干渉せず、いつでもきれいな状態から試せる。チーム間のデータ分離の仕組みが、デモでもそのまま動く** |

## 決定

案Bを採用する。

- 見本チーム(テンプレート)を1つ用意し、ログインのたびに複製する
- 各デモチームは作成から24時間で削除する。毎晩、期限切れのデモチームの削除と見本チームの作り直しを行う
- 乱用を防ぐため、同じIPアドレスからの作成は1時間20回まで、同時に存在するデモチームは500までとする

## 結果

良くなること:

- 訪問者どうしのデータが混ざらず、不適切な入力が他人に見えない
- マルチテナントの分離が、デモの体験そのものとして示せる

悪くなること・受け入れるコスト:

- 複製と削除の処理が必要になり、案Aより実装が増える
- 作成数が増えるとDBの容量を使う。上限と毎晩の掃除で抑え、作成数・存在数を監視する

## 見直す条件

- 複製の処理時間が目標(3秒以内)を守れなくなった場合
